# Sea Turtle Stay Website

## Run locally
Open `index.html` in a browser. For best local behavior, use VS Code Live Server.

## Main features
- Responsive premium resort landing page
- Booking enquiry form with date validation
- WhatsApp enquiry integration (+91 95901 94284)
- Multiple activity selection
- Room cards and dynamic starting price
- Gallery with lightbox
- Floating WhatsApp button
- Admin prototype at `admin.html`
- Room prices and content editable without touching the public page code (browser-local demo storage)
